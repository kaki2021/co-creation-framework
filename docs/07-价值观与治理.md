# 价值观与治理

共创平台需要稳定维护一组核心价值。成员、项目和工具可以变化，价值观负责说明哪些做法值得保留，哪些效率不能用来交换。

原演示文稿使用“自心成息”和《道德经》中“孳、检、不敢为天下先”的表达，并以“三桑无枝、各得其昌”说明人才成长后的关系。下面保留这些原意，同时把它们写成可以执行的组织规则。

> 我恒，有三葆。一曰孳，二曰检，三曰不敢为天下先。

## 一、自心成息：先让每个人成为清楚的个体

每个成员加入组织时都有自己的目标、需要和时间精力边界。成员愿意共创，不代表个人生活、技能和时间自动归集体支配。

成员需要清楚表达：

- 自己希望获得什么经验、成果或关系；
- 已经具备哪些能力，哪些部分需要帮助；
- 当前可以投入多少时间，能够承担到什么程度；
- 哪些条件变化后，需要调整承诺或退出。

组织需要做到：

- 任务开始前确认承诺，不把临时热情当成长久义务；
- 允许成员拒绝超出边界的工作，也允许按规则退出；
- 贡献值只记录项目贡献，不用来评价一个人的全部价值；
- 公开岗位需要的能力和责任，不以私人关系代替说明。

## 二、孳：让成员不断长出新的能力

原稿用“孳”表达培养、生长和延续。团队完成项目的同时，也要让成员获得以后能够独立工作的能力。

这意味着：

- 有经验的成员要分享方法、说明判断过程并提供反馈；
- 新成员可以先从边界清楚的工作开始，再逐步承担完整任务；
- 任何成员都可以提出想法，资历不自动决定意见的价值；
- 关键岗位设置副手或接班人，避免经验只留在一个人手里；
- 成员可以从执行者成长为任务负责人、项目负责人，最终也能发起自己的项目。

培养不能变成永久的师徒依附。成熟的结果是对方能够独立判断、独立承担结果，也有能力帮助后来的人。

## 三、检：言有依据，事有章法

原稿中的“检”包含自我约束、节制和持续修正。团队需要流程，但流程的作用是让人知道依据、边界和责任，不是增加无意义的手续。

在实际工作中：

- 重要判断要说明来自经验、数据、规则还是个人推测；
- 事实、判断和愿望分别记录，避免把愿望写成已经确定的事实；
- 使用公共预算、资料和账号时留下必要记录；
- 任务、版本、验收和决定采用共同格式，方便后来复查；
- 发现错误时及时修正，不用维护面子代替解决问题；
- 工具和人工智能提供建议时，必须显示依据和假设。

节制也包括不过度消耗公共资源。能用简单表格跑通的制度，不急着开发复杂软件；能在相邻岗位解决的问题，不把所有人拉进会议。

## 四、不敢为天下先：重大权力受到共同约束

原稿用“不敢为天下先”提醒负责人，不要把个人执着放在共同利益之前。它要求谦逊和克制，也要求重大决定获得足够支持。

具体规则包括：

- 日常、局部、可以撤回的决定交给岗位自行处理；
- 改变共同方向、公共规则、重要预算和对外承诺时，让受影响者参与；
- 负责人主动说明信息和理由，利益冲突者回避验收或表决；
- 集体作出决定后，执行人按决定推进，同时保留异议和复查日期；
- 紧急情况下可以先处理风险，但必须补充记录并接受事后复核。

共同决策不等于所有事情都投票。参与范围应当与影响范围相称，否则团队会把时间耗在无关决定上。

## 五、三桑无枝与各得其昌：内部平等，外部合作

原稿把组织的长期成果放在人才上。团队培养出来的人可以留在原项目，也可以进入其他行业、建立新的节点或与原团队继续合作。

对内应当做到：

- 基本人格、表达权、知情权和申诉权对所有成员平等开放；
- 不因成员资历、岗位或贡献值形成身份优越；
- 主动了解彼此不同的工作方式和需要，减少小团体和信息壁垒；
- 为成员提供方法、资料和真实的实践机会；
- 支持成员在团队内验证创意，并在条件成熟后发起新项目。

对外应当做到：

- 不主动攻击外部个人和组织，也不靠制造对立获得关注；
- 对外说明实际能力、成果和边界，不做超过证据的自我标榜；
- 把精力放在真实价值和可靠合作上；
- 合作协议只约束共同部分，各方保留自己的目标和内部治理。

## 六、五种需要长期培养的能力

原演示文稿曾借用故事人物说明五种能力。人物映射属于具体产品表达，公有框架只保留通用部分。

| 能力 | 在组织中的表现 |
| --- | --- |
| 判断与担当 | 信息不完整时说明依据、作出决定并承担结果 |
| 沟通与协作 | 理解上下游需要，及时说明变化和风险 |
| 各司其职 | 在自己的权限内完成闭环，不把责任不断向外推 |
| 场态轮换 | 能进入不同位置理解系统，也能完成交接和退位 |
| 组织决策 | 维护共同方向，组织受影响者形成可执行的决定 |

岗位轮换的目的，是让这些能力在真实工作中成长，不是给成员贴永久标签。

## 七、价值观怎样进入治理

| 决策层级 | 处理范围 | 常用方式 |
| --- | --- | --- |
| 岗位自主 | 局部、可撤回、不影响公共承诺 | 岗位直接决定并记录 |
| 相邻协商 | 影响少数依赖节点 | 相关岗位说明影响并达成一致 |
| 项目治理 | 影响全项目、重要预算或对外承诺 | 讨论后按约定程序决定 |
| 公共治理 | 改变平台规则、公共资产或成员基本权利 | 公示、审议、表决并设置复查期 |

价值观也要进入考核。担任负责人时，除了贡献和能力，还要检查是否尊重成员边界、是否如实说明依据、是否愿意交接权力、是否能在分歧中保护共同规则。

## 八、争议处理

先判断争议属于事实、规则还是价值选择：

- 事实争议补充证据，重新核对交付物和记录；
- 规则争议先说明现行规则怎样处理本次，再讨论以后是否修改；
- 价值冲突让受影响者参与，不能只靠公式决定；
- 权力和利益冲突由没有直接利益关系的人主持复核。

争议处理保留解决问题所需的信息，不公开无关的个人细节。任何规则都要允许提出异议，也要防止用反复争论阻止已经形成的合法决定继续执行。
