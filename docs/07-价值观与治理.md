# 价值观与治理

价值观只有进入选择和规则，才会真正影响项目。下面每一条都对应一个可以执行的治理要求。

## 先尊重人的边界

每个人都有自己的目标、需要、时间和精力限制。加入共创不等于把个人生活交给集体，也不等于必须对所有事情保持同样投入。

对应规则：任务开始前说明承诺；允许清楚退出；不把临时热情当成长久义务；不以贡献值衡量人的全部价值。

## 让成员能够独立发起事情

好的共创不是不断增加追随者，而是让参与者逐渐具备独立判断、组织资源和发起项目的能力。

对应规则：关键岗位设置副手；记录完整上下文；允许成员从参与任务走向主持任务；成熟项目可以分化出新的独立节点。

## 用事实约束判断

意见可以自由提出，但涉及工作量、质量、预算和风险时，要尽量给出证据。资源有限，不能把未经验证的判断包装成确定事实。

对应规则：重要评估写明依据和假设；区分事实、判断和愿望；保留版本和决策记录；允许复查。

## 重大决定不由一个人替所有人作出

日常工作应尽量分散决定，改变共同方向、公共规则和重大承诺的事项则需要共同参与。

对应规则：明确决策分层；利益冲突者回避验收；重要规则设复查日期；紧急决定事后必须补充说明和追认。

## 内部平等，外部合作

成员可以有不同能力、责任和贡献，但基本人格、表达权和申诉权相等。对外合作不要求彼此合并，也不要求一方放弃自己的目标。

对应规则：权力来自明确职责，不来自身份优越；合作协议只约束共同部分；不得用信息差长期控制关键资源。

## 决策分层

| 层级 | 处理范围 | 常用方式 |
| --- | --- | --- |
| 岗位自主 | 局部、可撤回、不影响公共承诺 | 岗位直接决定并记录 |
| 相邻协商 | 影响少数依赖节点 | 相关岗位达成一致 |
| 项目治理 | 影响全项目、重要预算或对外承诺 | 讨论后由约定程序决定 |
| 公共治理 | 改变平台规则、公共资产或成员权利 | 公示、审议、表决并设置复查期 |

## 争议处理

先判断争议属于事实、规则还是价值选择：

- 事实争议，补证据并复核记录；
- 规则争议，按现行规则处理本次，再决定是否修订未来规则；
- 价值冲突，不能只靠公式，需要让受影响者参与并保留不同选择的空间。

无法内部解决时，可以请没有直接利益关系的人主持调解。调解记录只保留解决问题所需的信息，不公开无关的个人细节。
