# 共创协作框架

这不是某一款产品的说明书，也不是某个项目的工作记录。这里整理的是一套可以反复使用的共创方法：人怎样发起事情、组成协作关系、独立完成工作、计算贡献、共同作出决定，并在项目变化时及时调整。

这套框架想解决的不是“怎样让所有人听从一个中心”，也不是“取消一切管理”。它关心的是另一件事：怎样把必须共同遵守的规则说清楚，同时把具体工作的判断权还给最了解现场的人。

## 先说明三件事

- **去中心化不等于没有中心。** 项目仍然需要共同方向、公共账本和争议处理机制，只是不让一个中心包办所有决定。
- **岗位自主不等于各干各的。** 每个岗位都要知道自己的目标、权限、输入、输出、验收标准和求助条件，然后在这个范围内自主行动。
- **贡献值不等于人的价值。** 它只是一种项目内部的记录和分配工具，不能拿来给人分等级，更不能代替信任、判断和协商。

## 资料边界

这套文档整理自早期的共创平台设计和试运行材料，只保留可复用的方法。具体产品的剧情资料、任务、提案、会议记录、成员资料、账号信息和内部评估结果都不在这个仓库中。

目前它是一套可以试运行的框架，不是不可修改的章程。真正采用时，应先用小项目跑一轮，再根据实际争议修订参数。
